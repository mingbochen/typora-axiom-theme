# Axiom development preview

浅色 ChatGPT 风格的 Typora 主题：白色正文、黄色强调色、暖白侧栏，以及按参考 App 核对的系统字体和 Codex 代码配色。

**这是开发预览版。** 浏览器排版、真实 MathJax / Mermaid 引擎集成和代表性 Typora DOM 检查已完成；原生 Typora 编辑交互及原生 HTML / PDF 导出仍待验收。当前预览图是浏览器夹具，不是实机截图。

## 下载与安装

- `axiom.css`：只需这一个文件即可安装，无需插件或联网字体。
- `axiom-v*.zip`：主题、示例、安装说明与验证记录。
- `*.zip.sha256`：对应 ZIP 的完整性校验值。

打开 Typora 的“偏好设置 → 外观 → 打开主题文件夹”，复制 `axiom.css`，重启后在主题菜单中选择 **Axiom**。

## 已修复的主要问题

- 对齐参考配置的 `#f6c543` 强调色与 `#1a1c1f` 前景色。
- 使用核对后的系统字体栈；在开发机器上，英文为 Segoe UI，中文为微软雅黑，英文代码为 Consolas。
- 修复导出任务列表中复选框与多段落标签分离的问题。
- 修复文件树大字号拥挤及选中背景越出圆角的问题。
- 为宽块级公式提供局部滚动与打印适配；长行内公式适配窄屏，并保持普通行内公式的基线。
- 修复聚焦模式的淡化样式泄漏到打印样式的问题；屏幕上的聚焦效果保持不变。此项通过代表性 DOM 和本机基础 CSS 检查，仍不替代原生导出验收。
- 修复表格中的长标识符撑出打印纸张的问题；屏幕上的原生横向滚动保持不变。
- 清除打印样式中遗留的打字机模式顶部留白，保留屏幕上的居中编辑效果。

部分参考代码配色的对比度低于普通文本 AA 标准，已在仓库验证记录中说明。复杂行内公式在窄屏可能缩小；若要保持字号，可以改用块级公式。

完整范围与限制见仓库的 `docs/QA.md` 和 `CHANGELOG.md`。本预览不取代原生编辑器验收，不标记为稳定版。
